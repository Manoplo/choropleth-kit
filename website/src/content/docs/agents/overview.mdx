## What you can use today

The rest of this site is already written to be read by an agent as well as by a person:

- [Map options](/reference/options/) lists every option in one page, grouped by purpose, with which ones depend on the `variant`.
- [What to import from where](/imports/) says which entry point holds what.
- [Error and warning messages](/reference/errors/) maps every `[choropleth]` message to its cause and fix.
- [Recipes](/recipes/) and the [Examples gallery](/gallery/) show the exact source of each running example.
- The library's own messages name the option involved and say what to pass instead, so an agent can fix most mistakes from the console output.
