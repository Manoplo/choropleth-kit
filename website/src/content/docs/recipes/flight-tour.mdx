## How it works

- `useRef<ChoroplethMapHandle>` gives you the imperative handle on the map.
- Every move returns a **promise**, so `await` chains flights in order. No timers, no guessing durations.
- `zoomTo` takes a region id (`"ES"`), `{ bounds }` as `[[lonW, latS], [lonE, latN]]`, or `{ center, zoom }`.
- A flight resolves with `completed: false` if the user interrupts it with a gesture. Check it before continuing a story.

## Variations

- Instant placement: `zoomTo("ES", { duration: 0 })`.
- Declarative instead: `focusId={currentId}` flies whenever the id changes.
- Read the camera: `map.current.getView()`, or `onViewChange` (fired once at the end of each gesture or flight).
