## How it works

- `selectedId` and `onSelectedIdChange` make the selection **controlled**: your state is the source of truth, and the panel reads from it.
- Clicking the selected region again calls `onSelectedIdChange(null)`.
- The map dims everything except the selection (`dimOthers` defaults to `"selection"`).
- The panel is plain React. `aria-live="polite"` announces changes to assistive technology, which the map itself does not do yet (see [Accessibility](/guides/accessibility/)).

## Variations

- Uncontrolled: pass `defaultSelectedId` and read the value from `onItemClick`.
- Fly to the selection: add `focusId={selectedId}`.
- Only dim on hover: `dimOthers="hover-and-selection"`.
- Open a custom tooltip instead of a panel: [`renderTooltip`](/guides/interaction/).
