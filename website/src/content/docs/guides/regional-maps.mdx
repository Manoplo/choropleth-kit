---
title: Regional maps
description: Show a continent, a subregion, a political grouping or a list of countries from the first frame.
---

`region` restricts the map **from the first frame**: no zoom animation, no world around it, and the map fills its container.

```tsx
<ChoroplethMap geography={world110m} objectName="countries" region="europe" data={rows} /* … */ />
<ChoroplethMap /* … */ region="westernEurope" />       // a subregion
<ChoroplethMap /* … */ region="eu27" />                // a political or commercial grouping
<ChoroplethMap /* … */ region="ES" />                  // one country
<ChoroplethMap /* … */ region={["ES", "PT", "MA"]} />  // some countries
<ChoroplethMap /* … */ region={["iberia", "MA"]} />    // presets and codes can be mixed
```

## Presets

Presets live in `REGION_PRESETS` (from `choropleth-kit/geo`):

- **Continents:** `africa`, `asia`, `europe`, `northAmerica`, `southAmerica`, `oceania`.
- **UN subregions:** `westernEurope`, `southeasternAsia`, `caribbean`, `usAndCanada`, and more.
- **Groupings:** `eu27`, `nordics`, `iberia`, `latam`, `mena`.

An unknown name throws an error that lists the valid ones.

## Behavior worth knowing

- **Russia is in no preset.** It spans two continents and would dominate the framing. Ask for it with `region="RU"`. Turkey, Cyprus and the Caucasus count as Asia.
- **Regions across the date line are re-centered.** Oceania (Fiji, New Zealand…) and Russia (Chukotka) would be torn across both edges of a world map, so their projection is rotated. Regions that do not touch ±180° keep the world's orientation.
- **Overseas territories are left out** (French Guiana, Svalbard, Hawaii…) so they do not shrink the framing.
- **Your data can be worldwide.** Rows for countries outside the region are ignored without warnings and listed in `joinReport.outOfRegion`. A typo (`"UK"`) still warns.
- **It works with `drill`.** `region` restricts the root level; the levels below bring their own geometry, and going back up returns to the region.
- It matches `feature.id` (or your `getFeatureId`) against ISO alpha-2 codes, so it needs a geography that uses them, like `world110m`.

## Remove regions you do not want

Antarctica is **not drawn by default** (almost no thematic map wants it, and it takes a huge share of a world map). Add it back with `showAntarctica`:

```tsx
<ChoroplethMap showAntarctica /* … */ />
```

For anything else `region` does not cover, `filterFeatures` discards shapes before anything else:

```tsx
filterFeatures={(f) => f.id !== "GL"} // no Greenland
```

## Aspect ratio

Use `aspectRatio="auto"` to derive the map's proportion from its geometry (Chile comes out tall, Norway wide). The default is 960 / 500, the world's proportion.
