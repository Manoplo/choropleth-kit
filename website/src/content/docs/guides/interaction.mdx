## Click and hover

```tsx
<ChoroplethMap
  {...common}
  onItemClick={(item) => console.log(item.kind, item.id)}
  onItemHover={(item) => console.log(item?.id)} // null on leaving
/>
```

`item.kind` tells a region from a bubble or point. `onItemHover` is called only when the item changes. On touch, the first tap counts as hover.

## Selection

The library can hold the selection for you, or you can control it.

```tsx
// Controlled
const [selectedId, setSelectedId] = useState<string | null>(null);

<ChoroplethMap
  {...common}
  selectedId={selectedId}
  onSelectedIdChange={setSelectedId}
/>;
```

- Uncontrolled: pass `defaultSelectedId` and let the library keep the state.
- Clicking the selected region again gives `null`.
- `dimOthers` decides what gets dimmed: `"never"`, `"selection"` (default) or `"hover-and-selection"`.

You can also react in your own `onItemClick`, for example `onItemClick={({ id }) => setSelectedId(id)}`.

## Style one region by its data

`getRegionStyle` applies per-region exceptions the scale cannot express:

```tsx
<ChoroplethMap
  {...common}
  getRegionStyle={(r) => (r.datum?.estimated ? { opacity: 0.6, pattern: "hatch" } : undefined)}
/>
```

Priority: `getRegionStyle` over the scale color over `emptyFill`. Do not set `fill` on `.cm-region` in CSS: it would beat the data.

## Tooltips

By default the tooltip shows the region's name and formatted value. Replace its content with `renderTooltip`:

```tsx
<ChoroplethMap
  {...common}
  renderTooltip={({ label, formattedValue }) => (
    <b>
      {label}: {formattedValue}
    </b>
  )}
/>
```

In the compound API, use `<Choropleth.Tooltip>` and pass your render function as its child.

### The whole datum is there

`renderTooltip` receives more than the value of the region. Its `datum` field is **the row you passed in `data`, as it is**, with every field of your object. The value that colors the map (`getValue`) is only one of them, so you can show any other field next to it:

```tsx
type Row = { id: string; currentData: number; lastYearData: number };

<ChoroplethMap<Row>
  data={rows}
  getId={(row) => row.id}
  getValue={(row) => row.currentData} // what colors the map
  renderTooltip={({ label, datum }) =>
    datum === undefined ? (
      <b>{label}: no data</b>
    ) : (
      <div>
        <b>{label}</b>
        <div>Now: {datum.currentData}</div>
        <div>Last year: {datum.lastYearData}</div>
      </div>
    )
  }
/>;
```

- `datum` is `undefined` for a region without a row. Check it before you read a field.
- With `<ChoroplethMap<Row>` (or the compound `Choropleth.Root<Row>`), `datum` is typed as your row.
- The default box (`cm-tooltip--default`) only wraps the default content. Your content has no background or border: style it yourself, or use `--cm-tooltip-*` variables on your wrapper.

## Legend interaction

Hovering a legend class highlights its regions. Turn it off with `legend={{ interactive: false }}`.

## Cursor

When there is an `onItemClick`, regions get a `pointer` cursor automatically.

## Dots: the map as a lattice

`dots` draws the map as a lattice of dots instead of filled regions. Each dot takes the color of the region under its center, and every region with a value gets at least one dot, even the small ones.

```tsx
<ChoroplethMap {...common} dots />
<ChoroplethMap {...common} dots={{ gap: 8, size: 0.6, lattice: "square" }} />
```

- `gap` is the distance between dots, in pixels (default 6). `size` is the dot's diameter as a fraction of the gap (default 0.7). `lattice` is `"hex"` (default) or `"square"`.
- Hover, click, the tooltip, selection and the legend highlight work as on the filled map. The hovered and selected regions get a halo around their dots.
- Borders and region patterns are not drawn with dots.
- Known limits: the dots do not stop growing when you zoom in (a cap is planned), there are no ocean dots, and drill-down levels are not drawn with dots yet.
