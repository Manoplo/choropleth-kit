## What you can rely on today

- choropleth-kit is **pre-1.0**. The API may change between minor versions, and breaking changes are made without a compatibility alias.
- The package is published on [npm](https://www.npmjs.com/package/choropleth-kit) and the source is on [GitHub](https://github.com/Manoplo/choropleth-kit).
- Planned features and known issues are tracked, one document each, in the repository's [`evolution-and-issues/`](https://github.com/Manoplo/choropleth-kit/tree/master/evolution-and-issues) folder.

See also [Known limitations](/project/limitations/).
