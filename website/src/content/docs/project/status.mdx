choropleth-kit is **pre-1.0**. The current version is on [npm](https://www.npmjs.com/package/choropleth-kit) and the source is on [GitHub](https://github.com/Manoplo/choropleth-kit).

## What you can rely on

- **The three API levels** (`<ChoroplethMap>`, the compound `<Choropleth.*>` pieces and the headless `useChoropleth`) and the variants `sequential`, `diverging`, `categorical` and `bubble`.
- **Zoom, pan and programmatic flights** (`zoomTo`, `focusId`, `resetView`), and **drill-down** between levels.
- **Subdivisions** of several countries (`choropleth-kit/geo/admin1/*`), regional maps (`region`), region and marker labels, and theming.
- **Graticule, background patterns and 32 pattern presets**, and **marker presets** (shape, pulse, glow, label, tooltip).

## Breaking changes are normal before 1.0

The API may change between minor versions. Breaking changes are made without a compatibility alias, and each one is noted in the [changelog](/project/changelog/). Pin the minor version if you need stability.

## Recently shipped

- **Dot-matrix renderer** (`dots`), in 0.5.0: the map drawn as a lattice of dots. Its limits are listed in [Known limitations](/project/limitations/).

## Planned

These are tracked, one document each, in the repository's [`evolution-and-issues/`](https://github.com/Manoplo/choropleth-kit/tree/master/evolution-and-issues) folder. The order is not a promise.

- **Click to zoom** on regions and markers, with a custom easing and a maximum zoom for focus.
- **Full accessibility**: arrow-key navigation between regions, an alternative table and live announcements.
- **Motion**: animations and an `animation` prop.
- **Export** to SVG and PNG.
- **Globe**, **point clustering** and a **framework-free API**.

See also [Known limitations](/project/limitations/).
